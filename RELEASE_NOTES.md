# Promediatum v1.0.0 — Initial Desktop Release

Personal academic workspace for independent educators.

## Highlights

- **Standalone desktop application** for macOS and Windows — no server required
- **Local-first architecture** with SQLite — your data never leaves your machine
- **Complete academic workflow** — periods, groups, students, attendance, weighted grades, observations
- **Export engine** — Generate PDF, Excel, CSV, and JSON reports with customizable templates
- **Insights engine** — Automatic risk detection, trend analysis, and attendance pattern recognition
- **Encrypted backups** — AES-256-CBC encrypted `.pdbk` backup files
- **Auto-update** — Built-in update system via GitHub Releases
- **Bilingual** — Full Spanish and English interface

## What's Included

### Core Academic Modules
- Period management with activation control
- Groups with student assignment and grade categories
- Student registry with multi-group membership
- Daily attendance tracking with consecutive absence alerts
- Weighted grade system with category-based scoring
- Typed observations with resolution workflow

### Export & Reporting
- PDF, Excel, CSV, and JSON export formats
- Customizable export templates with column selection and sorting
- Export history with download management
- SMTP email integration for report delivery

### Intelligence & Automation
- Composite risk scoring engine
- Trend analysis and grade trajectory detection
- Attendance pattern recognition
- Rule-based suggested actions
- In-app notification system with cooldown deduplication

### Desktop Features
- NativePHP + Electron packaging
- Native OS menus and notifications
- Encrypted backup/restore with validation
- Auto-update with safe migration and rollback
- Persistent storage in OS application data directory

### Design
- Café Pedagógico design system
- Light/dark/system theme support
- Configurable sidebar position and text weight
- Context-aware floating action button (FAB)
- Bento-grid workspace layout

## System Requirements

- **macOS:** 10.15 (Catalina) or later
- **Windows:** 10 or later
- No internet connection required for daily use

## Getting Started

1. Download the installer for your platform
2. Install and launch Promediatum
3. Create your first account (local-only, no email verification needed)
4. Set up your first academic period and start adding groups
